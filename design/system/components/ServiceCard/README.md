# ServiceCard

One workshop, session or game night: what happens, price per person, group price, duration, and a WhatsApp booking button.

- Copy and prices come from the client's brand profile (DESIGN.md §7). Prices are shown as given; the site does not take bookings or payment for services.
- The button links to `https://wa.me/972543992424?text=<prefilled message naming the service>`.
- Group cards in a 1-column list on phones, 2 columns from 768px.

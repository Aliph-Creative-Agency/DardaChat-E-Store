# JourneyChoice

The 2D chrome of a Journey decision point: progress, the scene prompt, three choice cards; picking one dims the others and lifts the choice.

- Always three choices, labelled أ ب ج, fully keyboard operable (they are buttons).
- The prompt is written in second person, warm and informal. Scene content is placeholder until the client's concept document arrives.
- This chrome floats over the 3D scene on a `surface` panel; it must stay AA readable over any frame.

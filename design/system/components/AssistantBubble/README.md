# AssistantBubble

The storefront assistant panel: automation disclosure in the header, sky bubbles for the assistant with a source line, blue bubbles for the customer, typing dots.

- The header's second line is the required "automated" disclosure (FR-AI-011) and always offers WhatsApp.
- Every factual answer ends with a `dc-msg__src` line naming where it came from.
- Never used inside the back office.

# Chip

Small pill labels for who a box is for, age, season and counts.

- `dc-chip--age` (blue) for the age rating, always "+12" / "+18" / «لكل الأعمار».
- `dc-chip` (sky) and `dc-chip--pink` for audience: family & friends, couples.
- `dc-chip--season` (red, white text) only for the Ramadan season window.
- `dc-chip--outline` for counts from "what's in the box"; wrap the number in `dc-num`.
- Consumer provides the text; keep it to 1–3 words.

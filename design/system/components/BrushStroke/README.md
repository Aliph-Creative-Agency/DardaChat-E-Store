# BrushStroke

Loose pink brush strokes that paint themselves onto the blue band — the motif from the client's logo banner.

- Use in hero bands and page headers only: pink (`brush`) strokes on `blue`, or `dc-brush--blue` strokes on `cream`.
- Two strokes, bleeding off opposite edges. Never behind body text.
- Draw once on load (`is-drawing`); click the band here to replay. Reduced-motion shows them drawn.
- The logo image is a placeholder crop from the brand profile until the client sends the SVG.

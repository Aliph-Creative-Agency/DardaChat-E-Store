# PriceTag

Shekel price, VAT-inclusive, with an optional was-price.

- Prices are agorot formatted with Latin digits and isolated LTR inside Arabic (`dc-num`).
- Always show «شامل الضريبة» (VAT included) under a product price; totals show VAT as an "of which" line elsewhere.
- Never set a price in the display face. (Prototype prices are placeholders until the client supplies real ones.)
